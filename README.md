# DuckDialer

A responsive, interactive phone dialer inspired by the visual language and interaction patterns of Samsung One UI's Phone app. This is an independent frontend recreation for learning and prototyping, not an official Samsung product.

## Run it

Open `index.html` in any modern browser. No build step, framework, or dependencies are required.

## Included

- One UI-inspired light and dark appearance
- Recents with All, Missed, Received, and Dialed filters
- Contacts list, favorites, search, and add-contact sheet
- T9-style numeric keypad and matching contact hint
- Simulated outgoing-call screen with mute, speaker, keypad, Bluetooth, and end-call controls
- Responsive mobile layout with safe-area support

## Notes

This is a browser prototype. It does not access the device's SIM, call log, contacts provider, or telephony APIs. Calls are simulated in the interface. Contact changes are kept in memory for the current page session.
